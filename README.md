# Colour Card Game

A standalone, phone-friendly card game against a casual computer opponent.

Open `index.html` to play locally. No install or build step is needed.

## GitHub Pages

Commit and push these files. In the repository Settings > Pages, select Deploy from a branch, choose your branch and the / (root) folder, then save.

The game will be available at https://jeremyt21.github.io/Colour-Card-Game/ after deployment.

## Checks

Run `node --test engine.test.mjs`.
